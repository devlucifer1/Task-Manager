Task Manager

A simple command-line Task Manager built with C++.

Features

- Add new tasks
- View all tasks
- Delete tasks
- Mark tasks as completed
- Unmark completed tasks
- View completed tasks
- View incomplete tasks
- Save tasks using a text file

Technologies

- C++
- "fstream"
- "string"
- File handling
- Command-line interface

How It Works

The program stores tasks in a "tasks.txt" file.

Incomplete tasks are stored like this:

[ ] Learn C++

Completed tasks are stored like this:

[✓] Learn C++

Menu

1. Add Task
2. View Tasks
3. Delete Task
4. Mark Task as Complete
5. Unmark Task as Complete
6. View Completed Tasks
7. View Incomplete Tasks
8. Quit

Run

Compile the program:

g++ manageday.cpp -o manageday

Run it:

./manageday
